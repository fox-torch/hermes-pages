Privacy Policy — Hermes (personal agent)

Last updated: 2026-10-25

Overview

Hermes is a personal, single-user software agent operated by its developer for the developer's own use. It runs on the developer's own computers and connects to the developer's own Google account through Google APIs.

Data the application accesses

With the account owner's authorization, the application accesses the following Google user data, in read-only form:

  • Gmail: message metadata and content, to summarize and search the owner's mail.
  • Google Calendar: calendar and event data, to review the owner's schedule.
  • Google Drive: file metadata and content, to locate and read the owner's files.

How the data is used

Data is used solely to provide personal-assistant functions to the account owner: answering the owner's questions, preparing summaries, and carrying out tasks the owner requests. Data is processed on the developer's own machines.

Storage and sharing

  • Google user data is not sold, rented, or shared with third parties.
  • Data is not used for advertising, and no advertising profiles are built.
  • Data is not transferred to other parties except as transient processing required to operate the agent (for example, sending the owner's own request context to the AI model providers the owner has configured).
  • Stored data remains under the owner's control on the owner's devices and can be deleted by the owner at any time.

Retention and deletion

The owner may revoke the application's access at any time from the Google Account permissions page (myaccount.google.com/permissions), which stops all further access. Locally stored data can be deleted by the owner at any time.

Contact

Questions about this policy can be directed to the developer contact email shown on the application's OAuth consent screen.
